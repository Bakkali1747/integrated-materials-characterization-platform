# XRD 峰分析

v0.18.0 实现 PRD Phase D 的 XRD 基础分析：读取显式文本格式，检测峰、计算 FWHM、d 间距与 Scherrer 表观尺寸，可选线性背景扣除与参考峰列表匹配，输出图、峰表、追溯记录、DOCX/PDF 报告，并接入样品工作区的 Measurement → AnalysisRun 闭环。

## 支持格式

支持 `.csv`、`.txt`、`.xy`、`.dat` 四种文本格式：

- `.csv` 默认逗号分隔；`.dat` 默认制表符；`.txt`、`.xy` 默认空白分隔。
- 有表头时按列名选择 2θ 与强度列，可使用 `2theta`、`two_theta_deg`、`2θ`、`angle` 与 `intensity`、`counts`、`cps` 等别名。
- 无可识别表头时只接受恰好两列，按（2θ，强度）处理；其他无表头布局直接拒绝。
- `#` 起始行视为注释；`header_row` 可跳过文件开头的若干内容行。
- 2θ 必须严格递增；重复、递减、缺失、非数值、非有限值直接报错并列出源行。
- 不排序、不插值、不平滑、不裁剪；原始文件只读并记录 SHA-256。

当前**不支持**厂商专有二进制格式（如未公开的 `.raw`、`.brml` 等）。未知结构不会被按列位置猜测。

## 峰检测

1. 可选背景：分别在用户给定的左侧窗口与右侧窗口内取平均强度，用两点连线作为线性背景；窗口至少各 2 个点，默认关闭。
2. 在背景扣除后的强度上寻找局部极大值。
3. 用地形突出度过滤：突出度 < 最大强度 × 最小相对突出度（默认 2%）的峰不报告。
4. 按突出度从高到低贪心保留，要求与已选峰的最小 2θ 间距（默认 0.1°）。
5. 峰位取扫描网格上的极大点，不插值、不拟合峰形。
6. FWHM 在峰半高处对左右相邻点线性插值；若峰在扫描范围内没有回落到半高，FWHM 与尺寸记为不可计算。
7. 相对强度以本次检测到的最高峰为 100%。

峰位、FWHM 均为离散数据估计；不声称完成峰形拟合或结构精修。

## d 间距与 Scherrer 尺寸

```text
d = λ / (2 sinθ)，θ = 2θ/2
D = K λ / (β cosθ)，β = FWHM（弧度）
```

- 波长 λ 必须由用户显式给出（Å；界面默认 Cu Kα1 = 1.5406，可修改）。
- K 默认 0.9，可修改。
- D 以 nm 输出，是**未做仪器展宽校正**的表观尺寸；不能直接当作真实晶粒尺寸。
- FWHM 接近扫描步长时会警告，Scherrer 结果不确定。

## 参考峰匹配

参考文件为 CSV/TXT/XY/DAT，包含 2θ、强度，可选 `phase` 列。强度按每个物相的最大值归一化为百分比。

- 按参考峰相对强度从高到低，在容差（默认 0.2°）内与最近的未匹配实测峰配对。
- 输出每个物相的匹配分数（匹配参考权重 / 总参考权重）、匹配数、总参考峰数和逐峰偏差。
- 默认忽略相对强度低于 5% 的参考峰，可在配置中调整。
- 参考匹配只是筛查，不是物相鉴定；分数高不代表样品只含该相，也不替代数据库或 PDF 卡片核对。

## 输出与报告

每次运行创建 `output/sample_<样品名>/<时间_唯一编号>/`：

- `parsed_data.csv`：源行号、2θ、原始强度、背景、扣除后强度。
- `xrd_peaks.csv` / `xrd_peaks.json`：峰位、强度、突出度、FWHM、d 间距、Scherrer 尺寸、相对强度，以及背景、质量和警告。
- `phase_matching.json`：参考相匹配结果（启用时）。
- `analysis_record.json/txt`：源文件、SHA-256、波长、K、背景与峰参数、警告、Git、版本和状态。
- `figures/`：XRD 图谱与检测峰；启用参考匹配时增加参考相棒图。每张图同时生成 Origin 可用 `.data` 目录。
- DOCX/PDF 报告：基本信息、峰表（前 15 个）、图、警告、方法边界与追溯；不写绝对路径。

## 工作区与科研状态

在“工作区 → 样品详情”选择 XRD 测试，点击“用此测试开始XRD分析”，页面载入原始文件；确认波长与峰参数后开始。成功后自动登记 `xrd_peaks` AnalysisRun，保存结果、图片和导出引用。

- 检测到峰：`PENDING`；有警告：`WARNING`。
- 未检测到满足阈值的峰：`NOT_COMPUTABLE`。
- 失败或取消不登记。
- 永不自动升级为 `VALIDATED`。

## 边界

- 不支持 Rietveld 精修、全谱拟合、仪器展宽校正、织构或应力分析。
- 参考相匹配只使用用户提供的峰列表，不内置 PDF 数据库。
- 不自动扣除 Kα2，不自动平滑或基线拟合（线性背景需显式窗口）。
- 测试通过不代表完成真实仪器格式或物相鉴定验证。
