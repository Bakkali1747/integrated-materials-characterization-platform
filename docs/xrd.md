# XRD 峰分析

v0.21.0 实现 PRD Phase D 的 XRD 基础分析：读取显式文本格式和 Bruker RAW4（文本或二进制直读），检测峰、Pseudo-Voigt 峰形拟合、FWHM、d 间距与 Scherrer 表观/校正尺寸，可选线性背景扣除、仪器展宽校正与参考峰列表匹配，输出图、峰表、追溯记录、DOCX/PDF 报告，并接入样品工作区的 Measurement → AnalysisRun 闭环。

## 支持格式

支持 `.csv`、`.txt`、`.xy`、`.dat` 以及 Bruker RAW4（`.raw`、RAW4 文本 `.txt`）：

- `.csv` 默认逗号分隔；`.dat` 默认制表符；`.txt`、`.xy` 默认空白分隔。
- 有表头时按列名选择 2θ 与强度列，可使用 `2theta`、`two_theta_deg`、`2θ`、`angle` 与 `intensity`、`counts`、`cps`、`PSD` 等别名。
- 无可识别表头时只接受恰好两列，按（2θ，强度）处理；其他无表头布局直接拒绝。
- `#` 起始行视为注释；`header_row` 可跳过文件开头的若干内容行。
- 2θ 必须严格递增；重复、递减、缺失、非数值、非有限值直接报错并列出源行。
- 不排序、不插值、不裁剪；原始文件只读并记录 SHA-256。

未知厂商文本布局或专有二进制不会被按列位置猜测。

## Bruker RAW4

已用真实 Bruker RAW4 数据（A/B 各一对 `.raw` + `.txt`）验证：

- RAW4 文本以 `;RAW4.00` 开头，`[Data]` 段包含 `Angle, PSD,` 表头，数据为逗号分隔。程序读取 2θ 与强度，并核对 `NumberOfMeasuredData`、`Start`、`Increment`。
- 从 `[RangeHeader]` 读取 `ActuallyUsedLambda`（缺失时依次尝试 `AlphaAverage`、`Alpha1`）作为默认波长；界面自动填入，用户可覆盖。A/B 文件为 1.5418 Å。
- 读取 `[VarInfo]` 中的 SAMPLEID、`[RawHeader]` 日期时间等元数据，供追溯；不改变原始文件。
- 二进制 `.raw` 优先**直接解析**：定位头部几何签名（起始 2θ、步长、点数、波长）并读取文件尾部 float32 计数数组；校验点数、2θ 范围、有限非负计数与整数计数比例。运行记录保存几何头偏移、数据偏移与计数整数比例。
- 若直接解析失败，才回退同目录同名 `.txt` RAW4 转换文件，并明确警告；两种来源都失败时给出可操作错误。
- 已用真实 A/B `.raw` 验收：直接解析的 3888 个计数与 `.txt` 逐点完全一致，2θ 差异 < 5×10⁻⁵°（TXT 仅保留 4 位小数）；复制 A.raw 到无 TXT 的目录后仍可直接分析。

## 峰检测

1. 可选背景：分别在用户给定的左侧窗口与右侧窗口内取平均强度，用两点连线作为线性背景；窗口至少各 2 个点，默认关闭。
2. 可选峰检测平滑：对背景扣除后的曲线做移动平均（默认 5 点，1 表示不平滑）。该平滑**只用于峰检测与 FWHM**，原始强度、背景扣除结果和导出数据不做平滑；运行记录保存平滑点数。
3. 在检测曲线上寻找局部极大值。
4. 用地形突出度过滤：突出度 < 检测曲线最大强度 × 最小相对突出度（默认 5%）或峰顶 ≤ 0 的峰不报告。
5. 按突出度从高到低贪心保留，要求与已选峰的最小 2θ 间距（默认 0.1°）。
6. 峰位取扫描网格上的极大点，不插值、不拟合峰形。
7. FWHM 在检测曲线峰半高处对左右相邻点线性插值；若峰在扫描范围内没有回落到半高，FWHM 与尺寸记为不可计算。
8. 相对强度以检测到的最高峰净突出度为 100%。
9. 可选 Pseudo-Voigt 峰形拟合：对每个峰在局部窗口内拟合峰位、FWHM、η、幅度与线性基线（默认开启）。拟合 R² ≥ 0.8 时采用拟合 FWHM/峰位；否则保留半高插值结果，并在峰表中标记“拟合=否（插值）”。

真实 A/B XRD 数据强度低、噪声明显；默认 5 点平滑与 5% 突出度可抑制噪声峰。用户应按样品调整平滑点数、突出度与最小峰间距，并检查下方峰表。

峰位、FWHM 均为离散数据估计；峰形拟合为局部 Pseudo-Voigt，不声称完成全谱拟合或结构精修。

## 峰形拟合与仪器展宽

- **Pseudo-Voigt**：`η·Lorentzian + (1−η)·Gaussian`，局部线性基线；每个峰独立拟合峰位、FWHM、η、幅度与基线斜率。
- 拟合 R² ≥ 0.8 时采用拟合峰位与 FWHM；否则保留半高插值结果并标记 `fit_converged=false`。真实 A/B 数据中只有主峰（约 44.7°）拟合收敛，噪声较大的弱峰/宽峰保留插值结果。
- **仪器展宽校正**（可选）：
  - 常数 FWHM：适用于已知固定仪器展宽的近似；
  - CSV 曲线：两列（2θ，FWHM），在峰位处线性插值；超出曲线范围不外推，校正尺寸记为不可计算。
  - 校正假设：`β_obs² = β_sample² + β_instr²`（Gaussian 合成）。这是显式假设，不是对所有峰形的严格解卷积。
- 输出同时保留 `crystallite_size_apparent_nm`（未校正）与 `crystallite_size_nm`（启用校正后的值）；未启用校正时两者相同。

```text
d = λ / (2 sinθ)，θ = 2θ/2
D = K λ / (β cosθ)，β = FWHM（弧度）
```

- 波长 λ 优先使用用户显式值；RAW4 未提供时使用 `ActuallyUsedLambda`（缺失时回退 `AlphaAverage`/`Alpha1`）。界面从文件自动预填，用户可修改。
- K 默认 0.9，可修改。
- 未启用仪器展宽校正时，D 为**表观尺寸**，不能直接当作真实晶粒尺寸；启用校正后使用 `β_sample` 计算。
- FWHM 接近扫描步长时会警告，Scherrer 结果不确定。

## 参考峰匹配与 COD 自动匹配

### 用户参考文件

参考文件为 CSV/TXT/XY/DAT，包含下列任一组合：

- `2θ` + 强度；
- `d_angstrom`（或 `d`/`dspacing`）+ 强度；匹配时按分析波长换算为 2θ。
- 可选 `phase`、`formula`、`card` 列；同一 `phase` 的多张卡片会合并，卡片号/化学式保留在匹配记录中。

强度按每个物相的最大值归一化为百分比。

- 按参考峰相对强度从高到低，在容差（默认 0.2°）内与最近的未匹配实测峰配对。
- 输出每个物相的匹配分数（匹配参考权重 / 总参考权重）、匹配数、总参考峰数和逐峰偏差。
- 默认忽略相对强度低于 5% 的参考峰，可在配置中调整。
- 对每个物相独立匹配后，再按实测峰覆盖度对物相组合（最多 3 相）排序：输出覆盖峰数、强度权重覆盖率与未覆盖峰；同一实测峰不会被组合内重复计数。
- 参考匹配与组合排名只是筛查，不是物相鉴定；覆盖率高不代表样品只含这些相，也不替代 PDF 卡片核对或定量相分析。

### COD 无机物相库（默认自动）

页面默认勾选“自动匹配 COD 物相库”：分析后自动在 88,311 个 COD 无机相中 search-match，按参考覆盖与实测覆盖返回前 10 个候选，写入 `phase_library_matching.json`，界面摘要与报告显示前 8 个。

- 数据为 COD 开放晶体结构计算的模拟图谱，CC-BY-4.0，不是 ICDD PDF 卡片。
- 同分/同构相可能并列（如 bcc Fe/Cr），必须结合成分与卡片核对。
- 详见 [COD 自动物相匹配](phase_library.md)。

## 输出与报告

每次运行创建 `output/sample_<样品名>/<时间_唯一编号>/`：

- `parsed_data.csv`：源行号、2θ、原始强度、背景、扣除后强度。
- `xrd_peaks.csv` / `xrd_peaks.json`：峰位、拟合峰位、强度、突出度、FWHM（插值/拟合）、η、R²、d 间距、表观与校正 Scherrer 尺寸、相对强度，以及背景、质量和警告。
- `phase_matching.json`：用户参考相的独立匹配与多相组合覆盖结果（启用时）；`screening_only=true`。
- `phase_library_matching.json`：COD 物相库自动候选（默认启用）；包含分数、覆盖率与逐行匹配。
- `analysis_record.json/txt`：源文件、SHA-256、波长、K、背景与峰参数、警告、Git、版本和状态。
- `figures/`：XRD 图谱与检测峰；启用参考匹配时增加参考相棒图。每张图同时生成 Origin 可用 `.data` 目录。
- DOCX/PDF 报告：基本信息、峰表（前 15 个）、图、警告、方法边界与追溯；不写绝对路径。

## 工作区与科研状态

在“工作区 → 样品详情”选择 XRD 测试，点击“用此测试开始XRD分析”，页面载入原始文件；确认波长与峰参数后开始。成功后自动登记 `xrd_peaks` AnalysisRun，保存结果、图片和导出引用。

- 检测到峰：`PENDING`；有警告：`WARNING`。
- 未检测到满足阈值的峰：`NOT_COMPUTABLE`。
- 失败或取消不登记。
- 永不自动升级为 `VALIDATED`。

## 边界

- 不支持 Rietveld 精修、全谱拟合、Kα2 剥离、织构或应力分析。
- 仪器展宽校正只支持常数或用户提供的 2θ–FWHM 曲线，并采用 Gaussian 平方差假设；不自动从标准样反演仪器参数。
- 参考相匹配只使用用户提供的峰列表，不内置 PDF 数据库；多相组合覆盖排名不是定量相分析。
- 不自动扣除 Kα2，不自动平滑或基线拟合（线性背景需显式窗口）。
- 测试通过不代表完成真实仪器格式或物相鉴定验证。
