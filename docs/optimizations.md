# v0.9.4 使用优化

本版不修改 RL、EAB、阻抗或 S 参数科学计算公式。图片与 Origin CSV 继续独立输出，正式图的尺寸、DPI 和曲线内容沿用原设置。

## 导出恢复

覆盖旧输出时若提交失败，程序尝试分别恢复旧图片与旧数据。如果恢复本身也失败，会保留 `.f-...` 目录及 `RECOVERY.json`，错误消息给出绝对路径。`old_image` 和 `old_data` 是尚未恢复的旧输出；已经恢复的文件位于原目标。不要删除恢复目录。确认文件占用解除后，根据记录把备份复制回原目标；保留副本直到确认完成。突然结束进程可能留下同样的恢复目录，本版不自动猜测或执行恢复。

## 图片数据入口

每个 `.data` 目录增加 `index.csv`，包含文件编号、曲线名称、坐标标签/单位和数据行数。单样品页可点击“打开当前图数据目录”；S 参数和比较页可打开最近手动导出的图片数据目录；历史页可打开当前历史图片的数据目录。尚未导出的预览不会误指向其他厚度的数据。

## 厚度滑块

完成分析后移动滑块，松开时更新指定厚度 RL 曲线、RLmin、−10 dB 最大连续 EAB 及各独立频带。滑块遍历本次扫描的真实厚度网格，直接复用已有矩阵，不插值、不重新运行 RL 扫描。原分析摘要保持不变。

“保存当前图片”保存滑块当前厚度及独立数据；“导出全部图片”仍导出原分析快照的图组和原指定厚度。每条曲线的厚度保留在图例和数据索引中。

## 可选快速预览

默认保持完整自动导出行为。在单样品参数中勾选“快速预览”后，数值表与追溯记录照常保存，只生成基础预览；其余科研图在选择时后台生成。只保留一个额外科研预览，切换其他科研图会释放之前的预览引用。

此模式不自动保存高清图片。需要时使用“保存当前图片”或“导出全部图片”；仍按设置 DPI 导出图片与 CSV。运行记录标明 `figure_output=deferred_until_explicit_export`，历史目录中没有图不代表分析失败。快速模式不用于批量页面。

## 可视化导入映射

单样品、比较和批量页面的“可视化列映射 / 导入模板”允许选择一个 CSV/Excel 示例文件，预览六行数据，用下拉框配置五个字段、频率单位和虚部解释，可保存/读取 JSON 模板。修改后需要重新导入或扫描。Excel 预览使用左侧设置的工作表和表头行，与正式解析保持一致；CSV 使用现有逗号分隔解析规则。MEMP、SDAT 的适配规则不受此模板覆盖。

## 历史筛选及核验

历史列表可按样品、日期、配置文字、路径及运行状态筛选。默认先读取摘要和图片，明确显示“完整性尚未核验”；点击 SHA-256 按钮才完整核对所有记录产物。大文件逐块读取并支持取消，避免一次读入整个文件。历史扫描跳过图片数据目录和导出恢复目录。

## 参考 RL 对照

单样品页新增“参考 RL 数据对照”。参考 CSV 要求列名 `frequency_ghz,thickness_mm,rl_db`，单位 GHz / mm / dB。必须填写参考软件版本、样品和模型条件；尚未确认的条件应写明。

仅与已计算网格对齐，坐标匹配绝对容差为 1e-9 GHz / mm，不做插值或外推。报告逐点列出参考值、计算值、有符号及绝对偏差、是否在用户设置的 dB 容差内；未匹配点和非有限计算值单独标记，不丢弃。报告保存原参考文件、SHA-256、原分析记录摘要、条件说明和独立对照表，不改写原分析。

对照入口限于计算 RL，不接收实测 S11 作为金属背板 RL 的等价证据。即使全部点在容差内，也不自动更改 MEMP 验证状态或 SDAT candidate 状态。本版没有获得新的商业软件参考数据，实际外部验证仍待完成。
