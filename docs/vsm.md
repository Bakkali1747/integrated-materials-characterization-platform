# VSM 磁滞回线分析

v0.17.0 实现 PRD Phase C 的 VSM 基础分析：读取 VSM 原始文件（含 Lake Shore 风格 `.dat`），计算 Hc、Mr、Ms、方形比与回线闭合差，可选高场线性背景扣除与质量归一化，输出图、指标表、JSON 记录、DOCX/PDF 报告，并接入样品工作区的 Measurement → AnalysisRun 闭环。

## 支持格式与显式配置

支持 `.csv`、`.xlsx`、`.xls`、`.txt`、`.dat`。字段列必须显式指定，或使用唯一别名（例如 `field_oe`、`Field (Oe)`、`H`、`磁场`）。以下配置均需显式给出，程序不猜测：

- 磁场列与磁矩列。
- 磁场单位：`Oe`、`A/m`、`kA/m`、`T`、`mT`。
- 磁矩单位：`emu`、`A m^2`。
- 样品质量（mg，可选）；留空则只报告磁矩，不做质量归一化。
- Excel 工作表与表头行；`.txt` 默认制表符分隔，`.csv` 默认逗号分隔。
- 背景扣除模式：`none`（默认）或 `linear_high_field`；后者需要高场窗口 |H| ≥ 阈值。

缺失值、非数值、非有限值直接报错并列出源行；不排序、不去重、不插值、不裁剪。原始文件只读，运行记录保存 SHA-256。

## Lake Shore 风格 DAT

已按本项目的真实测量文件验证以下结构（GBK 文本）：

```text
ID=样品  Mass(g)=0.0298  Volume(cm^3)=0  ...  Unit=CGS  Room_T(℃)=22.3 ...
Hci(Oe)=9.64  Hci1(Oe)=...  Mr(emu)=...  Ms(emu)=...
Time(s)  Field(Oe)  Temperature(K)  Angle(deg)  Moment(emu)  Magnetization(Mass)(emu/g)  LockX(V)  LcokY(V)  Induction(Gs)
```

- 自动识别数据表头（含 `Field(...)` 与 `Moment(...)`），默认选择 `Field(Oe)` 和 `Moment(emu)`。
- 从文件头读取 `Mass(g)`，换算为 mg 并默认用于质量归一化；界面会填入质量并标注“DAT 文件头”。用户手动修改质量时覆盖文件头，若与文件头相差超过 1% 会警告。
- 从文件头读取 `Unit`；当前只接受 `Unit=CGS`（Oe/emu）。`Unit=SI` 明确拒绝，不猜测。
- 记录文件头元数据与仪器内置的 `Hci/Mr/Ms`，仅供核对；本程序仍独立计算指标，不直接复制仪器结果。
- 温度、角度等附加列可含 `NaN`；只要求所选磁场列和磁矩列有限。
- 编码优先 UTF-8，失败后回退 GBK；两侧都失败则报错。

未知厂商二进制 `.dat` 或结构不同的文本仍会拒绝，不会按列位置猜测。

## 单位换算

```text
1 Oe = 1000/(4π) A/m ≈ 79.57747154594767 A/m
1 emu = 1e-3 A·m²
1 emu/g = 1 A·m²/kg
```

内部统一保存 Oe 与 A/m 两列磁场、emu 与 A·m² 两列磁矩。质量归一化后的磁化强度单位为 `emu/g`（等同 `A·m²/kg`）。Hc 同时给出 Oe 与 A/m。

## 指标定义

- **Hc**：磁化强度 M=0 时磁场值的绝对值均值；分别在正、负场零交叉中取平均。相邻点之间使用线性插值，不构造额外曲线。
- **Hc+ / Hc-**：正场与负场零交叉的绝对值，分别报告。
- **Mr**：H=0 处磁化强度的绝对值均值，分支未跨越零场时为不可计算。Mr+ / Mr- 分别报告。
- **Ms**：最大场处的端值，取正负两端绝对值的均值；仅代表本次最大场下的磁化强度，不代表真实饱和。
- **方形比**：Mr / Ms。
- **回线闭合差**：同一最大场处不同分支端值之差；相对 Ms 超过 5% 时警告。
- **最大场**：max(|Hmin|, |Hmax|)。

Hc 与 Mr 依赖离散点线性插值，结果精度受扫描步长限制。若未形成完整往返分支、没有零交叉或无法确定端点，运行状态记为 `NOT_COMPUTABLE`，界面和记录明确显示不可计算，而不是填零。

## 质量归一化

提供样品质量时，磁矩除以质量（g）得到 emu/g；未提供时，所有磁化强度指标以 emu 为单位，并记录“未质量归一化”。质量必须为有限正数，不做默认值或估算。

## 高场线性背景扣除

背景扣除默认关闭。启用时：

1. 分别对正场高场区（H ≥ 阈值）和负场高场区（H ≤ −阈值）做最小二乘线性拟合。
2. 取两侧斜率的平均值作为背景斜率、两侧截距的平均值作为背景截距；这样可避免把铁磁饱和台阶误当作背景斜率。
3. 从全部原始磁矩中减去该直线，报告拟合斜率、截距、R²、点数与使用侧数。
4. 只有一侧高场点足够时仍可拟合，但明确警告“无法分离饱和项与背景截距”。
5. 每侧至少需要 3 个点；高场点少于 10 或 R² < 0.9 时警告。

背景拟合不修改原始文件，不改变原始数据表；`parsed_data.csv` 同时保存原始磁矩、背景值和扣除后磁矩。

## 输出

每次运行创建 `output/sample_<样品名>/<时间_唯一编号>/`：

- `parsed_data.csv`：源行号、Oe/A·m 磁场、emu/A·m² 磁矩、原始磁化强度、背景、扣除后磁矩、分析值。
- `vsm_metrics.json` / `vsm_metrics.csv`：Hc/Mr/Ms、方形比、闭合差、背景与质量信息。
- `analysis_record.json` / `.txt`：源文件、SHA-256、单位、配置、质量警告、Git、版本与状态。
- `figures/`：磁滞回线、原点附近放大图；启用背景扣除时增加背景图。每张图同时生成 Origin 可用的 `.data` 目录。
- DOCX/PDF 报告：基本信息、指标、图、警告、方法与追溯；不写绝对路径，不改变验证状态。

## 工作区与科研状态

在“工作区 → 样品详情”选择 VSM 测试，点击“用此测试开始VSM分析”，页面载入原始文件；确认单位与质量后开始分析。成功后自动登记 `vsm_hysteresis` AnalysisRun，保存结果目录、指标文件、图片和后续导出引用。

- 成功且无警告：`PENDING`。
- 成功但有警告：`WARNING`。
- 指标不可计算：`NOT_COMPUTABLE`。
- 失败或取消不登记运行。
- 任何情况下都不会自动升级为 `VALIDATED`。

## 边界

- 只支持显式列映射的 CSV/Excel/TXT；未知厂商二进制格式不解析。
- 不提供 Minor loop、FORC、温度依赖、角度依赖或一阶反转曲线分析。
- 不自动判定“已饱和”；Ms 仅是当前最大场端值。
- 背景模型只有关闭与线性两种；不提供多项式或用户背景文件。
- 测试通过不代表完成真实仪器格式或物理结果的外部验证。
