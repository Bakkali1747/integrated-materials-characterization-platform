# 自动多厚度 RL 曲线（v0.9.2）

单样品页面导入 ε/μ 数据，设置厚度下限、上限和步长，点击“开始分析”。无需逐个输入厚度。

在中央图类型列表选择“多厚度 RL 曲线（自动）”。软件从已计算的厚度扫描矩阵选取最多七个均匀分布的厚度行，并加入全局 RLmin 和存在时最大 EAB 对应的厚度；重复厚度合并，按厚度升序显示。若最优结果并列，叠图选首个代表，全部并列数据仍在原摘要中。扫描点少于七个时展示全部厚度。

每条线标明厚度（mm），横轴为 Frequency (GHz)，纵轴为 RL (dB)，虚线为 −10 dB。修改扫描范围或步长后重新分析即可更新图。图中不添加 PENDING VALIDATION 标题。

“保存当前图片”或“导出全部图片”支持 PNG/TIFF/PDF/SVG。运行目录自动保存 `figures/RL_multi_thickness.png`、`RL_multi_thickness.csv`（频率、厚度、RL 三列），以及记录中的 `multi_thickness_rl` 选择规则、行索引和精确厚度。

[COMMON] 这些曲线是根据同一样品 ε/μ 参数和已有单层金属背板模型计算得到的不同厚度结果，不代表逐厚度实测。曲线直接取本次扫描矩阵，不对频率或厚度插值，不截断 RL。没有有效 EAB 时仍绘制代表厚度和 RLmin 厚度。外部验证状态继续保留在界面和分析记录中。

历史结果不会自动改写；要生成新增图，请重新分析。S 参数页面不使用此功能。
