# 界面主题（v0.10.1）

本版只调整外观与布局，不修改任何科学计算、导出内容或验证状态。

## 视觉规范

- 主色：`#2563EB`（操作/选中），深色侧栏 `#14243D → #0B1524`。
- 页面背景：`#F3F6FB`；卡片与表格：白色，边框 `#E2E8F0`，圆角 8–12 px。
- 字体：Microsoft YaHei UI；正文 10 pt，页面标题 15 pt，首页标题 24 pt。
- 状态色：待验证琥珀、通过绿色、失败红色；均使用浅底 + 左侧色条，保持可读性。
- 控件：主按钮为实心蓝，次按钮白底描边，危险/取消使用 ghost 样式；输入框、下拉框、滑块、进度条、滚动条统一圆角与悬停反馈。

## 布局调整

- 侧栏：品牌名、版本徽章、导航胶囊、底部“本地计算 / 数据不外传”。
- 首页：大标题 + 快速入口卡片（单样品、S 参数、比较、批量、历史）。
- 单样品/S 参数/设置：页面标题与副标题；参数区为白色卡片。
- 历史：筛选、运行/图片选择、操作按钮分区；进度、取消、数据目录按钮按需显示。
- 任务页：空闲时隐藏进度条与取消按钮，任务开始时出现，结束后隐藏。

## 兼容性

- 主题通过 `gui/theme.py` 的样式表应用；Fusion 基础风格，不依赖外部图片资源。
- 图表仍使用 Agg + Figure，不因主题改变尺寸、DPI 或数据。
- 截图见 `output/ui-preview/`（仅本机预览，不提交 Git）。
