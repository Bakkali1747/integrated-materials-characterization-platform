# 界面主题（v0.12.0）

本版按 UI/UX 设计系统（Data-Dense Dashboard）调整外观与布局，不修改任何科学计算、导出内容或验证状态。

## 视觉规范

- 主色：`#1E40AF`（操作/选中），悬停 `#1E3A8A`；辅助蓝 `#3B82F6`。
- 强调色：琥珀 `#D97706`，仅用于待验证/警告，不用于普通操作。
- 页面背景：`#F8FAFC`；卡片、表格：白色，边框 `#DBEAFE`，圆角 8–12 px。
- 文字：正文 `#1E293B`；标题 `#0F172A`；次要说明 `#64748B`。
- 字体：Microsoft YaHei UI；正文 10 pt，页面标题 15 pt，首页标题 24 pt；KPI 数值使用 Cascadia Mono / Consolas。
- 状态色：待验证琥珀、通过绿色、失败红色；浅底 + 左侧色条，不只依赖颜色。
- 控件：主按钮实心深蓝，次按钮白底描边，取消/维护操作使用 ghost；输入框、表格、标签页、滑块、进度条统一圆角。
- 键盘焦点：按钮、输入框、表格、导航均有可见焦点环；输入框聚焦为 2 px 深蓝边。
- 图表：统一 Agg + Figure，主题不改变尺寸、DPI 或数据。

## 布局

- 侧栏：`DAILY WORKSPACE / FULL WORKSPACE`、版本徽章、“工作区”分组、底部模式与“本地计算”提示。
- 首页：两列入口卡片（01…），日常模式只显示 3 个入口；底部“计算约定”信息卡列出法向入射、均匀单层、理想金属背板、EAB 连续带宽、缺失数据不插值。
- 单样品：文件名/夹具识别为独立浅蓝提示条；结果区右侧 2×2 KPI 卡（最小 RL、最大 EAB、当前厚度 RL、当前厚度 EAB）+ 可滚动完整摘要。
- 参数面板：按“厚度与判定 / 高级选项 / 数据解析 / 输出”分组；日常模式隐藏高级组与 Excel 列映射等。
- 空状态：表格未导入时显示“尚未导入数据”提示；绘图区使用虚线卡片说明下一步。
- 历史：筛选、运行/图片选择、操作按钮分区；空闲时隐藏进度条与取消按钮。

## 兼容性

- 主题通过 `gui/theme.py` 应用；Fusion 基础风格，不依赖外部图片资源。
- 所有改动只影响展示；`analysis_record.json`、`.data` CSV、报告和验证状态保持原语义。
