# 日常分析流程（v0.11.0）

针对“同轴传输线法 `.memp` + 配对 `.sdat`、主要分析 ε/μ”的日常场景。

## 1. 默认界面

启动后为 **日常模式**，侧栏只显示：

- 首页
- 单样品分析
- 结果查看
- 设置

需要 S 参数、多样品比较或批量分析时，到“设置 → 界面模式”切到“完整功能”。切回日常模式不会删除任何结果。

## 2. 导入 `.memp`

拖入或选择 `.memp` 后，软件读取：

- 样品名称（表头，如 `0.2`）
- 测试类型、频率范围与点数
- ε′, ε″, μ′, μ″ 原始表

文件名 `0.2_2_18_401_25_20261020141657` 只解析为：

| 字段 | 值 | 用途 |
|---|---|---|
| `0.2` | 样品编号 | 不作为厚度 |
| `2_18` | 2–18 GHz | 填入频率范围 |
| `401` | 点数 | 提示 / 核对 |
| `25` | 25 °C | 提示 / 记录 |

## 3. 自动读取厚度

软件在同目录查找同编号的 `.sdat`，读取夹具块。文件名不再要求完整长后缀，以下都能配对：

```text
0.2_2_18_401_25_20261020141657.memp  +  0.2_S-parameter_2_18_25_20261020141657.sdat
0.2.memp                              +  0.2.sdat
0.2.memp                              +  0.2_S-parameter_2_18_25_20261020141657.sdat
0.2_2_18_401_25_20261020141657.memp  +  0.2.sdat
```

夹具块示例：

```text
L = 20.00 mm
A = 0.00 mm
B = 17.88 mm
D = 2.12 mm   ← 样品厚度，填入“RL 曲线厚度”
温度 = 25 °C
```

导入后界面显示：

> 文件名：2–18 GHz · 401 点 · 25 °C；0.2 为样品编号；同目录 S 参数：D=2.12 mm（样品厚度） · 25 °C · 同轴空气线。

- 只自动填 **RL 曲线厚度**，不改厚度扫描范围（默认 1–5 mm，可按需修改）。
- 找不到配对 `.sdat` 时保留用户当前厚度，不猜测。
- 自动填入后仍可手动修改；修改值会写入本次运行配置。
- 厚度来源（sdat 路径、SHA-256、L/A/B/D、温度）写入 `analysis_record.json` 的 `configuration.source_hints.fixture`，便于回溯。

## 4. 分析

点击“开始分析”。分析会生成全部科学图，下拉框按常用图优先的顺序列出，日常模式**不再隐藏任何已生成的图**：

- ε′ / ε″
- μ′ / μ″
- RL–频率曲线（指定厚度）
- RL–厚度二维图
- 多厚度 RL、四分之一波长、阻抗、Cole–Cole、衰减等全部图

批量和多样品比较在完整模式下使用；每个 `.memp` 会自动读取各自的 D，不再共用 2.0 mm。

## 5. 结果与导出

- 结果页顶部是本次运行摘要；完整 QC 与警告在右侧/下方。
- “保存当前图片…”“导出全部图片…”仍至少 600 dpi，并生成独立 `.data` CSV。
- “导出分析报告…（DOCX + PDF）”包含参数、结果、图和来源信息。
- 历史页只读已保存产物，不重新计算；日常模式隐藏归档/分享等维护按钮。

## 6. `.sdat` 页面

`.sdat` 是原始 S 参数，当前版本不做 NRW 反演，不声称得到 ε/μ。它用于：

- 查看 S11/S21/S12/S22 幅度、dB、相位
- R/T/A、屏蔽效能 SE
- Smith 圆图
- 核对夹具 D、温度与候选映射状态

日常 ε/μ 分析请以 `.memp` 为准。
