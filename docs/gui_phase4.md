# GUI Phase 4（v0.9.0）

## 默认设置

打开左侧“设置”，修改默认频率单位、厚度上下限/步长、指定曲线厚度、RL 阈值、输出目录、DPI 或手动导出格式，然后点击“保存并应用到参数面板”。此操作覆盖单样品、比较和批量页面的对应参数，并更新 S 参数的输出目录和图片 DPI；不会改变样品选择、虚部约定、列映射、已完成结果，也不会自动重新计算。

重新启动后会读取保存值。“恢复默认值”先恢复设置页草稿，点击保存才生效。正在分析或导出时，设置页锁定。

默认值：GHz、1–5 mm、0.01 mm、曲线厚度 2 mm、阈值 −10 dB、分析图 300 dpi、PNG。手动导出图片至少 600 dpi（用户设置更高时跟随），兼顾交互速度与投稿质量。缺失数据插值固定 OFF，不提供未经实现的 ON 开关。MEMP 的单位和 SDAT 的单位/字段映射仍由各自 parser/schema 解释；更改 CSV/Excel 默认单位后应重新导入文件检查。

源码设置文件位于项目 `settings/gui.json`，不纳入 Git。客户端设置文件位于 `%LOCALAPPDATA%\IntegratedMaterialsCharacterizationPlatform\settings\gui.json`，与安装目录分离。配置无效时保留原文件，显示提示并使用默认值；只有明确再次保存才替换它。写入失败时当前参数保持不变。

## 图片输出

分析运行继续保存 PNG 预览和原有追溯产物，DPI 使用参数快照中的默认设置。手动“保存当前图片”使用设置中的默认格式和 DPI，可以在文件对话框选择其他支持格式。

单样品、S 参数、多样品比较页面新增“导出全部图片”。选择目标目录后创建独立 `figures_时间_编号` 子目录，格式支持 PNG/TIFF/PDF/SVG。单样品导出本次结果的全部科学图，S 参数导出五种视图，比较导出十项指标图。理论/实验叠图可用“保存图片”单独导出。

全部导出在后台调用原绘图 API，从本次已完成结果重绘，不重新计算 RL、EAB 或 S 参数。每张图片完整写入后才移动到目标文件；取消会保留此前完整图片，`export_record.json` 记录来源运行、来源记录哈希、软件版本、DPI、格式、完成清单与取消/失败状态。不能把导出位置设在原分析目录内。

## 布局改进

历史页提供“摘要 / QC”“完整记录”“产物核对”三个标签，已有 PNG 自动适应可用区域。批量页面显示样品、状态、问题、检查建议和质量检查，而不是直接展示整段内部对象。

[KNOWN] 所有格式的研究验证状态沿用原记录。MEMP 虚部定义与商业定量对照仍未确认；SDAT 仍为 `candidate_high_confidence`。GUI 设置及客户端打包不代表厂商验证完成。

## 启动与验收

源码：`.\.venv\Scripts\python.exe run_gui.py`。独立客户端：安装 `MaterialsCharacterizationPlatform-Setup-0.18.0-win64.exe`，从桌面快捷方式打开。

建议测试：保存 300 dpi / SVG 后重启；确认参数恢复；完成一个样品并导出全部图片；打开历史目录检查缩放；对批量任务请求取消并核对已有结果保留。CLI `run_batch.py` 继续可用。v0.9 是本阶段软件版本，不提前声明 v1.0 或外部科学验证完成。
