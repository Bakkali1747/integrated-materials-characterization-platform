# GUI Phase 3（v0.8.0）

## 批量分析

1. 打开“批量分析”，选择原始数据文件夹。只扫描当前层的 `.csv/.xlsx/.xls/.memp/.sdat`，不递归，也不跟随符号链接。
2. 同目录同文件主名归为同一样品；每份来源独立显示解析状态、点数和频率范围。不同主名不会自动配对。
3. 设置厚度、阈值、文件单位、虚部约定和输出目录。材料文件复用单样品参数；S 参数保持原始频率点，厚度/RL 参数不适用于实测 S 数据。扫描失败可修正文件或参数后重新扫描。
4. 点击“开始批量分析”。材料来源调用现有材料分析 API；SDAT 调用现有 S 参数 API。每份文件独立处理，一个来源失败不阻止其他来源。
5. 点击来源行查看错误、质量检查和来源运行目录。底部显示成功、失败、警告、取消和未开始的**来源数**，不是配对后的样品数。

结果位于所选输出根目录的 `batches/时间_唯一编号/`。`sources.csv` 记录来源状态，`materials_summary.xlsx` 保存材料指标及全部并列明细（仅存在成功材料时生成）。独立子运行包含原有 Excel/CSV、图片和分析元数据；S 参数不混入 RL 指标表。`batch_record.json` 逐来源原子更新，记录每个来源的独立状态和结果位置。

点击“取消”后等待当前可安全中断的步骤结束。已完成文件保留；正在执行的来源标记取消，剩余来源标记未开始。程序不会强制终止线程或删除旧结果。取消期间不能立即关闭窗口；后台结束后可关闭。扫描取消保留旧列表。

## Quality Control

[KNOWN] 频率递增、缺失值、非有限值和重复频率的 PASS 来自正式严格 parser 的通过证据；没有完整证据的历史/失败记录显示 PENDING。运行失败另显示 FAIL。负值及核心返回的物理筛查疑点显示 WARNING，原始数值不裁剪。

[KNOWN] Complex convention、Parser validation 继续标记 PENDING。MEMP 虚部定义与商业软件对照尚未确认；SDAT 为 `candidate_high_confidence`，S21/S12 厂商顺序尚未确认。数据结构检查 PASS 不代表测量或厂商验证通过。

## 历史结果

打开“结果查看”，选择 output、样品或运行目录。扫描后在运行列表中选择一项；程序只读取 JSON/CSV 与已保存 PNG，不调用分析或绘图计算。下拉选择图片可浏览。

显示原始运行状态、完整 metadata、已有 summary，以及每个有记录产物的哈希核对结果：PASS / MISSING / CHANGED。无哈希的旧运行明确提示未核对。错误和取消记录不会被改成成功；无法解析的记录显示错误，完整异常保存在日志。包含越界产物路径的记录拒绝读取。

哈希核对只是相对于保存记录的完整性检查，不证明记录的真实性或科研结果正确性，也不是数字签名。历史查看不修改原目录，不把旧版本结果转换成当前版本结果。

## 启动与阶段边界

独立客户端：安装 `MaterialsCharacterizationPlatform-Setup-0.13.0-win64.exe` 后，从桌面快捷方式打开。

源码启动：`.\.venv\Scripts\python.exe run_gui.py`。CLI `run_batch.py` 继续可用。

本阶段不增加完整设置管理和后续界面优化；等待用户验收后再进入 Phase 4。安装包沿用已授权的独立客户端交付流程。
