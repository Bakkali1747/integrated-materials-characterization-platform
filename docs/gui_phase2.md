# GUI Phase 2 · v0.7.0

继续使用桌面快捷方式，或在源码目录运行 `.\.venv\Scripts\python.exe run_gui.py`。安装包更新已安装的同一客户端，不删除历史数据。安装版默认输出在 `%LOCALAPPDATA%\MicrowaveAbsorptionAnalyzer\output`。

## 单样品完整科研图

选择 ε/μ 文件，设置扫描厚度、曲线厚度、频率裁选和阈值，点击“开始分析”。图类型菜单现在包含 16 种视图：ε/μ、RL 曲线、RL 2D、RL 3D、组合/单独介电和磁损耗角正切、α、C0、Cole–Cole、四分之一波长估算、指定厚度复阻抗、阻抗模长二维图及两类 RL 对照图。仅一个厚度点时跳过三维面；不支持的非有限 RL 图会明确跳过，原数据保留。

计算/派生数据仍调用现有 core 与 `export_phase2`；GUI 不实现任何科学公式。所有图可后台导出 PNG/TIFF/PDF/SVG，手动导出至少 600 dpi。完整阻抗矩阵、派生量和辅助解释写入分析目录。缺失数据插值 OFF。

## 实测 S 参数

左侧“S参数分析”选择 `.sdat`，填写样品名及输出目录。默认候选映射仍为 `candidate_high_confidence`。可选择已有 JSON schema；未验证自定义配置保持 `unverified`，不提供“已通过厂商确认”开关。

点击“开始 S 参数分析”，之后选择 S11/S21/S12/S22 或全部，以及 Magnitude、dB、Real/Imag、Phase、R/T/A、SE 与 Smith，再点击“更新显示”。更新只重绘已有计算结果，不重算或插值。逐频率点表与完整 CSV 保留原始频率。相位使用主值，不展开。

v0.10.0 起逐点表增加 SE_R/SE_A/SE_T，并提供 Smith 圆图与 SE 曲线；SE 定义与无定义点见 docs/sparameters.md。

[COMMON] R/T/A 沿用现有核心在相容功率归一化假设下的定义。负 A 不 clip，任何负 A 都提示；界面也显示幅度、能量、互易性超容差点数与实际容差。数值筛查不等于确认厂商字段顺序或证明完整二端口无源性。

[KNOWN] `.sdat` 的 S21/S12 顺序仍待厂商确认。页面和图片始终显示候选状态。S11_dB 标为 Measured S11，不命名为材料模型的 RL。

## 理论 / 实测叠图

先在单样品页面完成 ε/μ 分析，再在 S 参数页面选择对应的理论运行，点击“理论 / 实验对比”。不会根据相似文件名自动推断来源等价；需明确选择。曲线标注 Calculated RL 与 Measured S11，保留两套原始频率网格。

[COMMON] 测量条件可能不同，实测 S11 和理想金属背板理论 RL 不一定应一致。该提醒持续显示；对照结果新建独立目录，记录两份源文件哈希、运行目录、理论厚度和未确认的条件等价状态，不修改原分析记录。

## 十项多样品比较

在“多样品比较”添加 ε/μ 文件，勾选目标样品。单样品完成的来源也会进入比较列表。全选、清空选择、反选可用；双击名称可编辑，样品名必须唯一。输入共同扫描参数后点击“分析勾选样品并比较”。CSV/Excel 的共同列映射和虚部选项与单样品一致。

十项图包括 ε′、ε″、μ′、μ″、tanδε、tanδμ、α、C0、各样品自身指定厚度的 RL、EAB 随厚度。不同厚度（例如各样品的 sdat 夹具 D 不同）也可以直接比较：RL 曲线按各自厚度绘制并在标题标注，厚度相同时显示共同厚度；记录保存 `curve_thickness_mm_per_sample`，此时汇总不构成同一厚度下的优劣排名。各样品保留自己的频率点，不创建共同插值网格。

摘要表点击表头排序；在相同频率网格下，对 RLmin 和最大 EAB 的全部并列最佳样品轻度高亮。不同网格会提示不能视为同条件优劣排名，并关闭这种高亮。

摘要位置字段取确定性首个并列代表，明确带星号；明细和 Excel 的 RL_minima/EAB_bands 表保留全部并列结果和频段。EAB 为 −10 dB 最大连续带宽，不将分离区间相加。一个来源失败不会给它填零，也不会丢失其他成功样品。

结果目录包含十项图和逐点长表、CSV/Excel 摘要、每个来源的独立分析记录及比较追溯记录。“打开结果 / Excel”进入该目录。

## 后台与阶段边界

解析、计算、绘图和导出在后台运行。任务期间其他分析页面暂时禁用以避免 Matplotlib 并发绘图，仍可导航。取消在当前步骤结束后生效，保留已经完整写出的结果，取消的运行不标为成功。

本阶段没有实现目录批量分析界面、完整 QC 页面、历史结果浏览或完整设置。这些属于后续阶段；原 CLI 功能保持可用。科研验证状态不因 GUI 升级而改变。
