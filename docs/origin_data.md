# 图片配套数据（v0.9.3）

图片内容、标题、曲线、布局及导出 DPI 均保持原有行为。新增的是图片旁的独立数据目录，不会把数据表写到图片里。

例如保存 `RL_multi_thickness.png`，同时生成 `RL_multi_thickness.png.data/`：

- `01.csv`、`02.csv` 等：实际曲线/网格的数据，每个数据集独立一个文件。
- `README.txt`：文件编号对应的曲线名、坐标标签、单位、行数及导入方法。
- `metadata.json`：同样的机器可读对应关系、图标题和数据格式说明。

CSV 使用 UTF-8 BOM、逗号分隔、首行列名，浮点数输出 17 位有效数字。CSV 是可导入 Origin 的通用文本格式，不是 Origin 专有 OPJU 工程文件。未使用 Origin 本体进行自动导入验收。

## 在 Origin 中使用

1. 找到所需图片的 `.data` 目录，先看 `README.txt` 选择对应曲线或网格文件。
2. 在 Origin 通过 CSV / Single ASCII（单个 ASCII）导入；具体菜单名称随版本变化。选择 UTF-8 和逗号分隔，首行为列名。
3. 曲线/散点文件中将 `X` 列设为 X，`Y` 列设为 Y。横纵轴名称和单位见对应说明。
4. 二维/三维图使用 `X`、`Y`、`Z` 列：通常 X 是频率 GHz，Y 是厚度 mm，Z 是 RL dB 或无量纲阻抗模长。可按 XYZ 网格生成等高图或三维图。

多样品或多通道曲线分别保存，保留各自原始采样点和频率网格，不补齐、不对齐。Cole–Cole 图导出的是图中的 ε′/ε″ 坐标。四分之一波长图的估计线和极小值散点分别保存。二维/三维数据直接来自计算网格，不是等高线顶点、像素或降采样曲面。

−10 dB 等参考线、阻抗显示范围单独标记为 reference，不当作测量点。NaN 表示未定义数据；无穷值保留。重新绘图时请自行选择合适的显示方式，软件不会静默补值或裁剪。

## 覆盖范围与已有结果

覆盖 CLI 和 GUI 的自动分析图片、批量图片、S 参数、R/T/A、理论/实测对照、比较图、保存当前图片及导出全部图片。PNG/TIFF/PDF/SVG 都额外输出独立 CSV，不改变图片格式和内容。

图片与对应目录成对保存：取消或提交失败时保留旧输出；全部导出取消后保留此前已完整保存的图片和数据。不会覆盖名称相同但不属于本软件生成的数据目录。分析产物哈希包含这些新文件。

已有历史图片不自动补写或修改。重新分析，或从当前已完成分析中重新导出，可生成对应数据。科研验证状态沿用原分析记录；增加 CSV 不代表厂商验证完成。
