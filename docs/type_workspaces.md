# 类型工作区：单样品 / 多样品比较 / 批量分析

v0.23.0 起，左侧导航按数据类型组织：

```text
电磁性能
  单样品分析
  多样品比较
  批量分析
VSM 分析
  单样品分析
  多样品比较
  批量分析
XRD 分析
  单样品分析
  多样品比较
  批量分析
S参数分析
  单样品分析
  多样品比较
  批量分析
```

完整模式下显示全部入口；日常模式只保留电磁、VSM、XRD 的单样品分析与历史结果，隐藏 S 参数和所有比较/批量入口。

左侧类型默认折叠，只显示数据类型；点击类型标题（▸）展开，再次点击（▼）收起。进入某个类型的单样品/比较/批量页面时，该类型会自动展开。

## 单样品分析

沿用原有页面：

- 电磁：ε/μ → RL、EAB、科研图；
- VSM：磁滞回线、Hc/Mr/Ms；
- XRD：峰检测、Pseudo-Voigt、d/Scherrer；
- S 参数：幅度 / dB / 相位 / RTA / SE / Smith。

## 多样品比较

当前比较页面接受**已完成运行目录**，不重新分析原始文件：

| 类型 | 叠加图 | 指标表 |
| --- | --- | --- |
| 电磁 | 原有 RL/EAB 比较（接受 ε/μ 原始文件） | 十项指标 |
| VSM | 归一化磁滞回线 | Hc、Mr、Ms、Mr/Ms、状态、验证 |
| XRD | 归一化图谱 | 峰数、主峰 2θ、d、FWHM、Scherrer |
| S 参数 | S11 / S21 dB | min S11、min S21、schema、状态 |

比较输出目录包含 `figures/`、`comparison_metrics.csv`、`comparison_record.json` 和 SHA-256。比较不会改变任何原运行。

添加运行目录即可；每个运行必须已完成且类型匹配。比较不插值、不重新拟合、不改变验证状态。

## 批量分析

批量页面扫描用户选择目录的**当前层**，对每个匹配文件独立分析：

| 类型 | 扫描后缀 | 输出摘要 |
| --- | --- | --- |
| 电磁 | `.csv`、`.xlsx`、`.xls`、`.memp`、`.sdat`（沿用原批量框架） | 十项指标 / S 参数 |
| VSM | `.csv`、`.xlsx`、`.xls`、`.txt`、`.dat` | Hc、Mr、Ms、Mr/Ms |
| XRD | `.csv`、`.txt`、`.xy`、`.dat`、`.raw` | 峰数、主峰 2θ、d |
| S 参数 | `.sdat` | min S11、min S21 |

每个来源有独立运行目录；单个失败不会中断其他来源。批量记录为 `batch_record.json`，逐来源状态为 `sources.csv`。

- VSM 批量的 `.dat` 会尝试读取文件头质量；无质量时仅报告磁矩。
- XRD 批量优先使用 RAW/RAW4 文件头波长，普通文本默认 1.5406 Å。
- S 参数 schema 仍为候选映射，批量不会升级验证状态。

## 边界

- 比较基于已完成运行，不能把不同条件的运行当作等价条件；输出明确列出来源与状态。
- 批量不推断缺失质量、波长或 schema；使用默认值时必须在结果中核对。
- 所有结果保持 PENDING/WARNING/NOT_COMPUTABLE，不自动升级为 VALIDATED。
